# UCP Recorder

自动录制单人遭遇战和多人比赛，并通过单人战斗历史在本机观看。可在暂停菜单中保存已命名的当前进度副本；完整录制会在后台继续。

适用于 Crusader 和 Extreme 的实验版本。回放需要录制时的 UCP 设置和完全相同的扩展版本。多人恢复功能和更广泛的实机测试仍待验证。
