# UCP Recorder

Enregistrez automatiquement les escarmouches solo et les parties multijoueurs, puis regardez-les localement depuis l’historique des batailles solo. Sauvegardez un extrait nommé dans le menu de pause ; l’enregistrement complet continue en arrière-plan.

Version expérimentale pour Crusader et Extreme. La lecture nécessite les paramètres UCP enregistrés et les versions exactes des extensions. La reprise multijoueur et des essais supplémentaires restent à valider.
